AIだけで「高級感ある3Dウェブサイト」を
10〜15分で作る手順

元動画：I Built a $5,000 AI Health Ring Website in 10 Minutes（Shreyas Raj / 17分）。
動画の手順をそのまま日本語化し、遊牧民ラボ向けのアレンジと私（羊の執事）の改善案を添えました。

この動画でできること

「商品（動画では健康リング）を主役にした、代理店なら数千ドル取るような3D・高級感のあるランディングページ」を、AIツールの組み合わせでほぼ無料・短時間で作り、ネットに公開するまでを一気通貫で見せています。

肝になる発想
  • 「待ち時間の並行作業」：AIにサイトの土台を作らせている間に、3Dモデルや画像・動画素材を作る。
  • 素材はAIで作り、組み立てもAIに任せる：人は「指示」と「素材集め」だけ。
  • 3Dは GLB、動画は外部ホスティング：Webで軽く動かすための定石。

全体フロー

③④⑤（珊瑚色＝素材づくり）は、②でAIがサイトを作っている裏で並行して進めるのがコツです。

0参考さがし（インスピレーション）

Pinterest / Dribbble / Landbook で「（商品名）website」のように検索し、作りたい雰囲気の参考を1枚決めます（例：health ring website）。

PinterestDribbbleLandbook

この1枚が、後の3Dモデル生成の「元画像」にもなります。

1サイトの土台を「並行ビルド」

Claude Code に「ワンショット構築プロンプト」（サイト全体を一発指示する長いプロンプト）を貼り、モデルを sonnet にして実行。動画では、ここで一旦走らせておき、その裏で素材を作ります。

無料でやるなら：Google の Antigravity（無料のAI IDE）。pricing から無料プランで agentic 開発ができます。
ポイント：素材が揃う前に土台を走らせておくと、戻ってきた頃にはサイトの骨格ができている＝時短になります。

23Dモデルを作る（GLBで書き出し）

Meshy AI に Step0 の参考画像を貼り付け → 画像から3Dモデルを生成（約20クレジット）。生成後に HDテクスチャを当てると、ツヤのある高級感のある仕上がりに。

  • 書き出し形式は GLB（Web・ブラウザ・スマホで最も軽く滑らかに動く定番形式）。
  • 無料代替：Tripo、または Meshy の無料枠（Meshy 5）。

3画像素材を作る（16:9 で）

背景・ライフスタイル用のプレミアムな画像を生成。動画では配布プロンプト集（mountain dawn、portrait lifestyle card など）を使い、各4枚ずつ・16:9の横長で出します。

無料でやるなら：Google Flow ＋ Nano Banana Pro。アスペクト比を16:9にして「4枚作って」と指示。毎回確認が出ないよう「クレジット確認＝しない」に設定すると楽。

4ヒーロー動画を作る（8秒ループ）

Step3の画像の1枚を使い、開始フレームと終了フレームに「同じ画像」を指定して、8秒のループ動画を生成（動画では Google Flow の VEO 3.1 light）。これでヒーローが滑らかに無限ループします。

合言葉：「同じ画像を開始フレーム＆終了フレームに。8秒のループで。」

5動画をホスティング（Cloudinary）

動画をサイトに直接置くと読み込みが激重になるので避けます。Cloudinary（無料・Gmailで登録）に動画をアップ → ストリーミングURLを取得して、そのURLをサイトで使います。

6素材をまとめて「組み立て」をAIに依頼

生成した画像を1つのフォルダ（例：ring-assets）にまとめ、Claude Code にこう指示します。

このフォルダの画像をサイトに使って：（フォルダのパス）
3Dモデルはこの GLB ファイルを使って：（GLBのパス）
ヒーロー動画はこのURLを使って：（CloudinaryのURL）
最後に表示崩れがないかテストしてから渡して。

Claude Code はPC内のフォルダを読めるので、フォルダを指すだけで素材を正確に組み込みます。

7公開（GitHub ＋ Netlify）

Claude Code に GitHub MCP / Netlify MCP を接続（「GitHub/NetlifyのMCPを設定して」と頼んで認証するだけ）すれば、「GitHubにpushして、Netlifyにデプロイして公開URLちょうだい」でターミナル無しに公開できます。

遊牧民ラボは準備済み：GitHubリポジトリは作成済みなので、あとは Netlify 接続だけで最短公開できます。

🦭 遊牧民ラボ向けアレンジ（同じ手順を、私たちの世界観で）

動画は「健康リング」でしたが、私たちは自作AIツールを主役にします。手順は同じで、置き換えるだけ：

  • 主役の3Dモデル → リングの代わりに「アザラシ」や各ツールを象徴する小物を Meshy で3D化（または既存のSplineアザラシを継続）。
  • 参考さがし → Pinterest で「product landing page 3D」「resort web design」。配色はモルディブ（ラグーン/サンド/珊瑚/サン）固定。
  • 画像・動画 → 16:9で「水・リゾート・アザラシ」のトーンに統一。ヒーロー動画は波が揺れる8秒ループ。
  • ワンショット構築プロンプト → 遊牧民ラボのブランド（呼称・配色・アザラシ・Lenis/GSAP）を固定したテンプレにして、ツールごとのLPを量産。

🐑 羊の執事の「より良い案」

動画の手順は優秀ですが、旦那様の環境（自宅GPU・無料/ローカル志向・既存資産）に合わせると、もっと安く・速くできます。

① 3Dは <model-viewer> で（無料・透かし無し）

Meshyで作ったGLBを、Google製の <model-viewer>（タグ1つで3D表示・回転・自動ライティング）で出すと、Splineの月額や透かしが不要。軽くてスマホでも滑らかです。

② 画像は自宅GPUでローカル生成も

RTX 5060 Ti があるので、ComfyUI＋SDXL等で無料・無制限・ネット不要に画像を量産できます（枚数を気にせず試せる）。仕上げだけ Nano Banana という併用も◎。

③ 短いループ動画は Netlify 直置きでも可

8秒・軽量に圧縮（WebM/H.264, 1〜2MB）すれば、Cloudinaryを挟まずNetlify直置きでも十分軽い。依存サービスを1つ減らせます（重い/長い動画ならCloudinary推奨）。

④ 「ワンショット構築プロンプト」をテンプレ資産化

遊牧民ラボの規約（ブランド・配色・フォント・Lenis/GSAP・アクセシビリティ）を1枚のテンプレにして、毎回それを土台に走らせる。2本目以降のツールLPが一気に速くなります。

⑤ GitHubは作成済み → 公開導線が最短

すでにリポジトリがあるので、Netlifyを繋げば「pushしたら自動で本番更新」に。動画の⑦⑧を1回設定すれば以後は自動です。

次のアクション

旦那様の合図で、私はこの手順に沿って動けます。おすすめの進め方：

  1. まず1ツール（例：音声入力）でテスト1本を、この手順で作る。
  2. 3Dは「Meshyで作る」か「既存Splineアザラシで行く」かを選ぶ。
  3. 画像生成は「自宅GPUローカル」か「Google Flow無料」かを選ぶ。
  4. OKなら、残りのツールへ横展開＋Netlay公開。

「より良い案」のどれを採用するか、または「動画そのまま通り」で行くか、教えていただければ着手します。
